Privacy Policy / 개인정보 처리방침

Effective date / 시행일: 2026-10-19

English

appleheap's tool is a private, single-owner command-line pipeline. It uses the YouTube Data API and the YouTube Analytics API through OAuth, only on the owner's own YouTube channels, to upload videos and to read channel statistics.

  • OAuth tokens are stored locally on the owner's computer only.
  • The tool collects no data from other users.
  • Nothing is shared with third parties.
  • Data obtained through Google APIs is not used for advertising and is not used to train AI or machine-learning models.

appleheap's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: you can revoke the tool's access at any time at myaccount.google.com/permissions.

Contact: appleheap@gmail.com

appleheap은 Google API에서 받은 정보를 사용하고 전송할 때 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
